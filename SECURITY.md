# Security policy

This repository is an offline synthetic assurance prototype. Do not submit real biometric templates, neural recordings, biological data, operational camera feeds, credentials, or customer evidence in public issues or pull requests. Use synthetic minimal reproductions.

If you find a vulnerability, report it privately to the repository owner through GitHub's private vulnerability reporting feature when available. Include the affected version, a minimal synthetic reproduction, expected versus actual behavior, and whether the issue could cause an unauthorized allow, evidence forgery, or data disclosure. Do not test against someone else's live devices or identity systems.

The project makes no deployment security or certification claim. The [threat model](docs/THREAT_MODEL.md) and [production target](docs/DEPLOYMENT.md) distinguish controls implemented here from controls required for a pilot.
